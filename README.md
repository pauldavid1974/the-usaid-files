# the-usaid-files
Search and verify the November 2026 USAID Files collection locally. The archive contains all 248 records listed by USAID, extracted PDF and spreadsheet text, timestamped video transcripts, and a ready-to-query SQLite index.

1. Download and extract the ZIP from the [November 2026 archive release](https://github.com/pauldavid1974/the-usaid-files/releases/tag/2026-11-25).
2. Open [START-HERE.md](START-HERE.md) or run `python research.py stats` from the extracted folder.
3. Check [the acquisition report](findings/ACQUISITION.md) for source provenance, verification and limitations.

The 248 binaries were independently hosted and matched the SHA-256 prefixes in the government catalog. The separately issued government ZIP was incomplete at the time of this snapshot.
